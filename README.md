# SSF Morocco RP — Website Starter

موقع ثابت مجاني بـ HTML وCSS وJavaScript، متجاوب مع الهاتف والكمبيوتر.

## الملفات
- `index.html` — صفحات الموقع والأقسام.
- `style.css` — التصميم المتجاوب.
- `app.js` — تغيير اللغة، الاستمارة، اختبار QCM، ولوحة الإدارة التجريبية.
- `supabase-schema.sql` — مخطط اختياري لقاعدة بيانات Supabase مع سياسات وصول أولية.

## تشغيله على الكمبيوتر
1. فك ضغط ZIP.
2. افتح مجلد `ssf-morocco-rp`.
3. افتح `index.html` في المتصفح. الاتصال بالإنترنت مطلوب لتحميل الخطوط وملف Supabase الاختياري.

## النشر المجاني باستعمال GitHub Pages
1. أنشئ حساباً في GitHub إن لم يكن لديك حساب.
2. اضغط **New repository** وسمّه `ssf-morocco-rp`.
3. اجعل المستودع **Public** إذا كنت تستعمل GitHub Free للنشر.
4. ارفع الملفات الموجودة داخل هذا المجلد إلى جذر المستودع، خصوصاً `index.html` و`style.css` و`app.js`.
5. افتح **Settings → Pages**.
6. تحت **Build and deployment** اختر **Deploy from a branch**.
7. اختر الفرع `main` والمجلد `/(root)` ثم اضغط **Save**.
8. انتظر اكتمال النشر، ثم افتح الرابط الذي يظهر في صفحة Pages. قد يحتاج النشر بضع دقائق.
9. أي تعديل ترفعه إلى الفرع والمجلد نفسهما سيُعاد نشره تلقائياً.

الدليل الرسمي: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## التخزين التجريبي
بدون إعداد قاعدة بيانات، تُحفظ الطلبات في `localStorage` على المتصفح الحالي فقط. لا تنتقل إلى جهاز آخر، ويمكن أن تُحذف إذا مُسحت بيانات المتصفح. لا تجمع معلومات حساسة بهذا الوضع.

## ربط Supabase مجاناً (اختياري)
يمكن أن تتغير حدود الخطة المجانية؛ راجع صفحة التسعير الرسمية قبل الاعتماد عليها: https://supabase.com/docs/guides/platform/billing-on-supabase

1. أنشئ مشروعاً في Supabase.
2. افتح SQL Editor وشغّل محتوى `supabase-schema.sql`.
3. من إعدادات API انسخ **Project URL** و**public anon/publishable key**.
4. افتح `app.js` واستبدل `SUPABASE_URL` و`SUPABASE_ANON_KEY` بالقيم الخاصة بمشروعك.
5. أنشئ حساباً إدارياً من Supabase Authentication.
6. امنح الحساب دور `admin` في `app_metadata` من واجهة الإدارة الآمنة/الخادم، وليس من كود المتصفح. قيمة الدور التي يتوقعها مخطط SQL هي `admin`.
7. سيُسمح للزوار بإرسال الطلبات فقط، بينما قراءة الطلبات وتعديلها محصوران بسياسة RLS بالحسابات التي لديها `app_metadata.role = admin`.
8. اختبر الإعدادات بمستخدم تجريبي قبل نشر الموقع الحقيقي.

**تحذيرات أمنية مهمة**
- لا تضع `service_role` key أو كلمات المرور أو مفاتيح خاصة داخل `app.js` أو أي ملف منشور.
- لا تعتبر لوحة الإدارة التجريبية آمنة إذا لم تكن قاعدة البيانات وسياسات RLS مفعّلة ومختبرة.
- لا تمنح الزوار صلاحية قراءة الطلبات. بيانات التقديم قد تكون شخصية؛ اجمع أقل قدر ممكن منها ووضّح سياسة الخصوصية.
- سياسة قاعدة البيانات المرفقة قالب بداية، ويجب مراجعتها واختبارها قبل الاستخدام الفعلي.
- لا تخزّن أسراراً أو بيانات شخصية حساسة في مستودع عام.
